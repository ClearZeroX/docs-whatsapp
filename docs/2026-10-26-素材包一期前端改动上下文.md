## 3. 关键接口

### 3.1 组合预览 `POST /admin/api/material/combination/preview`

前端入口：`src/api/materialCombination.js` → `previewMaterialCombinationAPI(data)`

**请求结构（前端当前实际发送）：**

```json
{
  "materialGroupId": 647,
  "combinationMode": "RANDOM",
  "current": 1,
  "size": 10,
  "materials": {
    "headerList": [{"id":"","tempKey":"header_0","status":"ACTIVE","materialCategoryCode":"UNCATEGORIZED","confirmDisableCombination":false,"subType":"IMAGE"}],
    "bodyList":   [{"id":"","tempKey":"body_0","status":"ACTIVE","materialCategoryCode":"zlc_test_1","confirmDisableCombination":false}],
    "footerList": [ "..." ],
    "buttons": {"type":"BUTTONS","subType":"TEXT","id":"...","element":{"type":"BUTTONS","buttons":["..."]}},
    "limitedTimeOfferList": [{
      "id":"","tempKey":"lto_0","status":"ACTIVE","materialCategoryCode":"UNCATEGORIZED",
      "type":"LIMITED_TIME_OFFER","subType":"NONE","confirmDisableCombination":false,
      "element":{"type":"LIMITED_TIME_OFFER","limited_time_offer":{"text":"限时优惠","has_expiration":false}}
    }],
    "carouselBodyList": [{"id":"","tempKey":"carousel_body_0","status":"ACTIVE","materialCategoryCode":"UNCATEGORIZED"}],
    "cardGroups": [{"ids":[82,83],"status":"ACTIVE","confirmDisableCombination":false}]
  },
  "memberFilter": {"type":"BODY","materialId":"...","tempKey":null}
}
```

要点：

- **`materials.cardIds` 已不再发送**（旧 2D 数组）；轮播卡片组走 `materials.cardGroups`
- 仅 LTO 需要补 `element`（后端按 element 校验 LTO），其余类型不补
- `carouselBodyList` 只发“有内容的项”或 `status=DELETED` 的项（空占位不发，避免误判轮播模板已配置）
- `memberFilter` 只在点单个素材看浮层列表时传；`manualCombinations` 只在手动组合模式传

**后端约定的返回口径（用户提供，前端已按此适配）：**

- `materialStatus` 只返回 `NORMAL` / `MATERIAL_PAUSED`（预览不再返回 `MATERIAL_DELETED`）
- 引用 PAUSED/DELETED 素材的**已存在组合仍然返回**（含 DB 中 `INACTIVE` 的行）
- 新候选不生成引用非 ACTIVE 素材的组合
- 组合 `status` 为模拟值：`DELETED + confirmDisableCombination=true → INACTIVE`；其余保持 DB 原值；多成员取最严重
- `typeSummary.<TYPE>` 字段：`hasMaterials`、`combinationCount`（含 INACTIVE）、`newCount`（仅候选）、**`activeCount`（可用数，本期新增）**、`blocked`、`blockedReason`
- 四个数字都不受分页 / memberFilter 影响；`total` 是分页前真实条数
- 顺序：已存在行在前、新候选在后，**前端不再二次排序**

### 3.2 组合稳定性（批量）

`POST /admin/api/material/combination/stability/batch`，入参 `{ combinationIds: [1001,1002] }`，返回 `data["<combinationId>"] = { utilityCount, totalTemplateCount, utilityPercent, historyUtilityCount, historyTotalTemplateCount, historyUtilityPercent, stabilityLevel, stabilityReason }`

- 前端：`fetchMaterialCombinationStabilityBatch(ids)`
- `/admin/api/material/stability/batch`（素材包主/备素材评级）**不在本期范围**，入参保持裸数组 `List<Long>`，已还原

## 5. 已确认的产品口径（决策记录）

1. 菜单后缀：素材包/素材组合模板都加 `-一级内容`/`-二级内容`，**渠道模板不加**；英文也加
2. 三张示例图可以压缩入库，但**内容/格式不能走样**
3. 组合类型下拉里的「普通模板」也改「经典模板」（关联处一并改）
4. 轮播内容素材/轮播卡片：只保证“本次新增的在上”，历史保持后端顺序（有 TODO 视情况再做全量倒序）
5. 预览过滤必须**后端过滤**，前端不做
6. 查看页素材【预览】调一次 `{ materialGroupId }`：随机组合展示全部，人工组合不展示；浮层只展示该素材过滤后的数据（后端过滤）
7. 「停止生成」语义：只影响新增候选，**保留已有组合**
8. 停用语义：`confirmDisableCombination=false` 保留组合；`true` 则组合停用
9. 「本字段必填」只针对新增行，历史行不校验
10. 稳定性展示在所有用到 `CombinationTable` 的地方统一（含素材包展开的二级列表、提交确认弹窗）
11. 预览接口 `materials.cardIds` 去掉；`memberFilter.cardIds`、响应 `records[].cardIds` 保留
