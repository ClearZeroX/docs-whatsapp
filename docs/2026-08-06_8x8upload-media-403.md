# 8x8 媒体上传失败确认（待对接方）

> 日期：2026-08-06
> 目的：IMG/VIDEO header 模板创建失败，需要对接方确认 8x8 `files` 上传端点的 subAccountId 取法。

## 一、现象

创建带 IMAGE header 的模板 `0806_test_8x8_6_media` 时：

1. 本地下载图片成功（OBS）。
2. 调用 8x8 上传文件接口失败：
   - 请求：`POST https://chatapps.8x8.com/api/v1/subaccounts/RupiahCepat_CA_WA/files`（multipart，字段名 `file`）
   - 返回：`HTTP 403`
   ```json
   {
     "code": 1201,
     "message": "Account was not found in SG. Please use the ID endpoint!",
     "errorId": "835e73d2-da65-47e2-8b2d-d7300d6307f1",
     "timestamp": "2026-08-06T..."
   }
   ```
3. 因图片未上传成功、拿不到 8x8 文件 URL，模板请求里 IMAGE header 无 example/sample。
4. 创建模板接口失败：
   - 请求：`POST /api/v1/accounts/RupiahCepat/channels/4f9478dd-b3db-475c-9e49-778d8c87046b/templates`
   - 返回：`HTTP 400`
   - `{"code":3032,"message":"Templates with IMAGE header type need an example/sample, but it was not provided. ..."}`
5. 模板状态最终置为 `CREATEFAIL`。

## 二、待对接方确认的问题

1. `POST /api/v1/subaccounts/{subAccountId}/files` 中 `subAccountId` 支持什么样的取值？
   - 我们目前传子账号名称 `RupiahCepat_CA_WA`，返回 `"Account was not found in SG. Please use the ID endpoint!"`。
   - 报错中的 `ID endpoint` 指什么？是否需要改成子账号的数字 ID？数字 ID 从哪获取？
2. 若有「数字 ID」，它与子账号名称 `RupiahCepat_CA_WA` 的对应关系是什么？
3. 发送消息接口 `POST /api/v1/subaccounts/{subAccountId}/messages` 是否同样要求使用数字 ID？（如果也要求，sendMessage 链路也需要改成同样的 ID 取值）
