# 素材模版限时优惠 LTO PRD

- 文档日期：2026-09-04
- 版本：v1.1
- 状态：待评审
- 文档定位：本文档描述素材模板页和人工组合页的 LTO 产品需求、业务规则、页面交互、接口字段变更、边界场景和验收标准。

---

# 1. 文档说明与需求总览

## 1.1 背景

WhatsApp Limited-Time Offer Templates（以下简称 LTO）可以在优惠码消息中展示优惠信息、到期时间和倒计时。本次需求在素材模板页支持配置 LTO 素材，并在人工组合中选择 LTO 素材，最终生成带 `LIMITED_TIME_OFFER` 组件的正式模板。

## 1.2 目标

1. 在素材模板页新增 LTO 素材配置区域。
2. LTO 区域位于【模板头部】和【模板内容】之间。
3. 支持添加多个 LTO 素材。
4. 每个 LTO 素材支持预览、停止生成、停用。
5. 人工组合页在【头部】和【内容】之间新增 LTO 选择槽位。
6. 一个组合最多选择一个 LTO 素材。
7. 组合可以继续选择“无 LTO”，保持普通模板行为。
8. 选择 LTO 后，组合必须满足 LTO 的 FOOTER、BUTTONS 约束。

## 1.4 名词解释

| 名词 | 解释 |
| --- | --- |
| LTO | WhatsApp Limited-Time Offer，限时优惠模板组件 |
| LTO 素材 | 素材模板下维护的限时优惠素材 |
| LTO 组合 | 人工组合中选择了 LTO 素材的组合 |
| 普通组合 | 未选择 LTO 素材的组合 |
| `hasExpiration` | 是否展示到期时间 |
| `expirationPolicy` | 到期策略，分为绝对时间和相对时间 |
| `expirationTimeMs` | 发送给 WhatsApp / BSP 的绝对到期时间，Unix 毫秒 |

| 需求编号 | 需求名称 | 优先级 | 需求说明 |
| --- | --- | --- | --- |

# 2. 业务规则与状态

## 2.1 通用业务规则

1. LTO 仅允许用于 `MARKETING` 模板。
2. 一个最终模板最多包含一个 `LIMITED_TIME_OFFER` 组件。
3. 一个素材模板下可以维护多个 LTO 素材。
4. 一个人工组合最多选择一个 LTO 素材。
5. 组合可以选择“无 LTO”；无 LTO 组合继续按普通模板处理。
6. 选择 LTO 的组合不允许配置 FOOTER。
7. LTO 策略保存在正式模板 `components` JSON 中。



## 2.2 到期策略

ABSOLUTE：绝对时间

RELATIVE：相对时间

###  时区

支持时区：

| 国家 | 时区 |
| --- | --- |
| 尼日利亚 | `Africa/Lagos` |
| 印尼 | `Asia/Jakarta` |
| 印尼 | `Asia/Makassar` |
| 印尼 | `Asia/Jayapura` |

前端可以考虑按国家给默认值：

```text
ID -> Asia/Jakarta
NG -> Africa/Lagos
```

## 2.3 LTO 素材状态

状态说明：（整体原则：和当前body类型素材保持一致）

| 状态 | 页面表现 | 是否可被组合选择 |
| --- | --- | --- |
| ACTIVE | 正常展示和编辑 | 可选 |
| PAUSED | 已停止生成 | 不可选 |
| DELETED | 不展示 | 不可选 |

生命周期影响：（整体原则：和当前body类型素材保持一致）

| 操作 | 影响 |
| --- | --- |
| 修改 LTO 素材策略 | 只影响之后新生成的正式模板 |
| 停用 LTO 素材 | 引用它的组合不可用，存量正式模板不变 |
| 删除 LTO 素材 | 引用它的组合不可用，存量正式模板不变 |
| 生成正式模板 | 将当时素材内容固化为 `message_template.components` |
| 发送消息 | 只读取正式模板 `components`，不回查素材表 |

# 3. 功能需求与页面交互

## 3.1 素材模板页区域调整

在素材模板新建 / 编辑页中，新增【限时优惠】区域。

区域顺序为：

```text
模板头部

限时优惠

模板内容
```

如果页面下方还有 FOOTER、BUTTONS 等区域，保持原有顺序不变。

## 3.2 区域默认态

初始状态下，如果当前素材模板没有 LTO 素材，展示如下：

```text
┌──────────────────────────────────────────────────────────────┐
│ 限时优惠                                          [ + 添加 ] │
└──────────────────────────────────────────────────────────────┘
```

1. 点击【添加】后新增一张 LTO 素材卡片。
2. 一个素材模板下支持添加多个 LTO 素材。
3. LTO 素材不影响【模板类型】的展示和选择。
4. 模板类型仍保持现有逻辑，例如“普通模板”/“轮播图模版”。

## 3.3 多个 LTO 素材样式

样式参考现有【模板内容】区域，支持多卡片。

示例：

```text
限时优惠                                                     [添加]

┌────────────────────────────────────────────────────────────┐
│ 限时优惠 LTO-01                          [预览] [停止生成] [停用] │
│                                                            │
│ 优惠文案：Offer ends soon                            16/16    │
│ 展示到期时间：开启                                            │
│ 到期方式：发送后 30 分钟                                       │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│ 限时优惠 LTO-02                          [预览] [停止生成] [停用] │
│                                                            │
│ 优惠文案：Flash Sale                                  10/16    │
│ 展示到期时间：开启                                            │
│ 到期方式：2026-09-10 12:00 Asia/Jakarta                      │
└────────────────────────────────────────────────────────────┘
```

## 3.4 新增 / 编辑 LTO 素材

点击【添加】后，新增一张 LTO 编辑区域

### 3.4.1 字段设计

| 字段 | 控件 | 是否必填 | 说明 |
| --- | --- | --- | --- |
| 优惠文案 | 输入框 | 是 | 最大 16 字符，对应 `limited_time_offer.text` |
| 展示到期时间 | Switch | 是 | 开启时对应 `has_expiration = true` |
| 到期方式 | Radio | 条件必填 | `展示到期时间 = 开启` 时必填 |
| 绝对到期时间 | DateTimePicker | 条件必填 | 到期方式为“绝对时间”时展示 |
| 时区 | Select | 条件必填 | 到期方式为“绝对时间”时展示 |
| 相对时长 | 数字输入 | 条件必填 | 到期方式为“相对时间”时展示，时间单位默认为分钟 |

### 3.4.2 优惠文案

- 输入框 placeholder：`请输入优惠文案`；
- 最大长度：16 字符；
- 超过最大长度时禁止继续输入；
- 字数统计展示：`0/16`；

### 3.4.3 展示到期时间

Switch 文案：

```text
展示到期时间
```

状态：

| 状态 | 值 | 说明 |
| --- | --- | --- |
| 开启 | `has_expiration = true` | 必须配置到期方式 |
| 关闭 | `has_expiration = false` | 不展示到期时间，不配置到期策略 |

关闭展示到期时间后，到期方式、时间、时区、相对时长等字段隐藏。

### 3.4.4 到期方式

开启【展示到期时间】后，展示：

```text
到期方式：
○ 绝对时间
○ 相对时间
```

默认值：

- 新建 LTO：默认选择【相对时间】；
- 编辑已有 LTO：回显当前策略。

### 3.4.5 绝对时间配置

当到期方式为【绝对时间】时，展示：

```text
到期时间：[2026-09-10 12:00]
时区：    [Asia/Jakarta]
```

默认时区：

| 国家 / 地区 | 默认时区 |
| --- | --- |
| 印尼 | `Asia/Jakarta` |
| 尼日利亚 | `Africa/Lagos` |

如果产品需要支持印尼多个时区，则下拉中额外支持：

- `Asia/Makassar`
- `Asia/Jayapura`

错误提示：

| 场景 | 提示 |
| --- | --- |
| 未选择时间 | `请选择到期时间` |
| 时间早于当前时间 | `到期时间必须晚于当前时间` |
| 未选择时区 | `请选择时区` |
| 时区不支持 | `当前时区不支持` |

### 3.4.6 相对时间配置

当到期方式为【相对时间】时，展示：

```text
发送后：[30] 分钟过期
```

单位：默认分钟

| 单位 | 转换 |
| --- | --- |
| 分钟 | `分钟数 × 60 × 1000` |

默认值：

```text
30 分钟
```

校验：

| 场景 | 提示 |
| --- | --- |
| 数字为空 | `请输入有效时长` |
| 数字小于等于 0 | `时长必须大于 0` |
| 非整数 | `请输入整数时长` |

## 3.5 LTO 卡片操作

每个 LTO 卡片右上角提供：

```text
[预览] [停止生成] [停用]
```

### 预览

点击【预览】后，打开预览弹窗或侧边栏。

预览内容模拟 WhatsApp 中 LTO 模板的展示效果

预览不发送消息，不产生正式模板创建请求。

### 停止生成

点击【停止生成】后，行为完全复用现有素材BODY的“停止生成”逻辑。

要求：

1. 后端字段和状态变化与现有 BODY 素材保持一致。
2. 停止生成后，卡片状态展示与现有素材一致。
3. 现有交互支持恢复生成，LTO 同样支持恢复。

### 停用

点击【停用】后：

1. LTO 素材状态更新为停用；
2. 卡片展示“已停用”标识；
3. 停用后不能被新的人工组合选择；
4. 已引用该 LTO 的人工组合应展示不可用状态；
5. 已生成的正式模板不受影响。

停用后样式建议：

```text
┌────────────────────────────────────────────────────────────┐
│ 限时优惠 LTO-01              已停用        [预览] [启用]        │
│                                                            │
│ 优惠文案：Offer ends soon                                     │
│ 展示到期时间：开启                                            │
│ 到期方式：发送后 30 分钟                                       │
└────────────────────────────────────────────────────────────┘
```

## 3.6 人工组合新增 LTO 槽位

当前人工组合中，每个组合包含：

```text
模板类型
头部
内容
脚部
```

本次在【头部】和【内容】之间新增：

```text
限时优惠
```

调整后结构：

```text
#1
* 模板类型：普通模板
头部：无HEADER
限时优惠：无 LTO
* 内容：内容
脚部：无FOOTER
```

规则：

1. 【模板类型】保持现有逻辑，不新增“限时优惠模板”。
2. 是否为 LTO 组合由【限时优惠】槽位决定。
3. LTO 槽位默认值为“无 LTO”。
4. 一个组合最多选择一个 LTO 素材。
5. 无 LTO 组合保持普通模板行为。

LTO 下拉选项示例：

```text
无 LTO
LTO-30分钟
LTO-Flash Sale
LTO-今日过期
```

素材状态与可选性：

| 素材状态 | 是否展示 / 可选 |
| --- | --- |
| ACTIVE | 展示且可选择 |
| PAUSED | 不展示，或展示但置灰 |
| DELETED | 不展示 |
| 停止生成状态 | 按现有 BODY 素材逻辑处理 |

## 3.7 选择 LTO 后的联动

用户选择 LTO 后，该组合变为 LTO 组合，需要立即触发以下联动：

1. FOOTER 强制置为 `无FOOTER`；
2. FOOTER 控件置灰；
3. 校验 BUTTONS 素材是否满足 LTO 要求；
4. 组合预览展示 LTO 区域；
5. 保存时执行 LTO 组合校验。

### FOOTER 联动

选择 LTO 后：

```text
脚部：无FOOTER（置灰）
```

提示文案：

```text
限时优惠模板不支持 FOOTER
```

交互建议：

- 用户选择 LTO 前，如果已经选择了 FOOTER，先记住原 FOOTER 选择；
- 用户选择 LTO 后，FOOTER 自动清空为 `无FOOTER`；
- 用户取消 LTO 或改回“无 LTO”后，恢复之前选择的 FOOTER；
- 如果恢复时原 FOOTER 素材已不可用，则保持 `无FOOTER`。

### BUTTONS 校验

#### `hasExpiration = true`

当前组合的按钮素材必须满足：

1. 已选择 BUTTONS 素材；
2. BUTTONS 中第一个按钮是 `COPY_CODE`；
3. `COPY_CODE.example` 非空；
4. 优惠码长度 ≤ 15。

如果校验失败，组合保存时报错：

| 场景 | 提示 |
| --- | --- |
| 未选择按钮素材 | `展示到期时间的限时优惠组合必须选择按钮素材` |
| 第一个按钮不是 COPY_CODE | `限时优惠组合的第一个按钮必须为 COPY_CODE` |
| COPY_CODE.example 为空 | `COPY_CODE 示例优惠码不能为空` |
| 优惠码超过 15 位 | `优惠码不能超过 15 个字符` |

#### `hasExpiration = false`

按钮校验按现有普通模板逻辑处理。

但如果按钮中包含 `COPY_CODE`，它仍然必须是第一个按钮。

#### 无 LTO

不应用 LTO 按钮校验，保持现有逻辑。

## 3.8 组合保存规则

### 无 LTO 组合

保存时：

```json
{
  "limitedTimeOfferMaterialRef": null
}
```

或：

```json
{
  "limitedTimeOfferMaterialRef": ""
}
```

组合保持普通模板行为。

### 有 LTO 组合

保存时必须携带：

```json
{
  "limitedTimeOfferMaterialRef": "66f1a2b3c4d5e6f7a8b9c0d1"
}
```

且必须满足：

1. LTO 素材存在；
2. LTO 素材属于当前素材模版；
3. LTO 素材状态可用；
4. LTO 素材策略合法；
5. 组合无 FOOTER；
6. BUTTONS 满足 LTO 校验。
