# 素材模版限时优惠 LTO 前端技术方案

- 文档日期：2026-09-04
- 关联 PRD：[2026-09-04-素材模版限时优惠LTO-PRD.md](2026-09-04-接入限时优惠模版（LTO）-需求文档.md)
- 范围：素材模板页 LTO 配置、人工组合 LTO 选择、相关接口接入
- 原则：复用现有素材交互；后端负责时间转换、策略校验和正式模板下发

# 1. 页面展示与交互

## 1.1 素材模板页

在【模板头部】和【模板内容】之间新增【限时优惠】区域。

### 无 LTO 素材

```text
┌────────────────────────────────────────────────────────────┐
│ 模板头部                                             [添加] │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│ 限时优惠                                                   │
│                                                            │
│ 暂无限时优惠素材。新增后可在人工组合中选择使用。                  │
│                                                 [ + 添加 ] │
└────────────────────────────────────────────────────────────┘

┌────────────────────────────────────────────────────────────┐
│ * 模板内容                                             [添加] │
└────────────────────────────────────────────────────────────┘
```

### 多个 LTO 素材

```text
┌────────────────────────────────────────────────────────────┐
│ 限时优惠                                             [添加] │
│                                                            │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ 限时优惠 LTO-01                      [预览][停止生成][停用] │ │
│ │ 优惠文案：Offer ends soon            16/16               │ │
│ │ 展示到期时间：开启                                      │ │
│ │ 到期方式：发送后 30 分钟                                 │ │
│ └────────────────────────────────────────────────────────┘ │
│                                                            │
│ ┌────────────────────────────────────────────────────────┐ │
│ │ 限时优惠 LTO-02                      [预览][停止生成][停用] │ │
│ │ 优惠文案：Flash Sale                 10/16               │ │
│ │ 展示到期时间：开启                                      │ │
│ │ 到期方式：2026-09-10 12:00 Asia/Jakarta                │ │
│ └────────────────────────────────────────────────────────┘ │
└────────────────────────────────────────────────────────────┘
```

## 1.2 LTO 编辑表单

### RELATIVE 示例

```text
优惠文案：[Offer ends soon]                                16/16

展示到期时间：[ON]

到期方式：
(●) 相对时间
( ) 绝对时间

发送后：[30] 分钟过期
```

### ABSOLUTE 示例

```text
优惠文案：[Flash Sale]                                     10/16

展示到期时间：[ON]

到期方式：
( ) 相对时间
(●) 绝对时间

到期时间：[2026-09-10 12:00]
时区：    [Asia/Jakarta]
```

字段规则：

| 字段 | 控件 | 必填 | 规则 |
| --- | --- | --- | --- |
| 优惠文案 | Input | 是 | 最大 16 字符 |
| 展示到期时间 | Switch | 是 | 关闭时隐藏策略字段 |
| 到期方式 | Radio | 条件必填 | `hasExpiration=true` 时展示 |
| 绝对到期时间 | DateTimePicker | 条件必填 | 必须晚于当前时间 |
| 时区 | Select | 条件必填 | 必须选择 |
| 相对时长 | InputNumber + Select | 条件必填 | 大于 0 |

时区默认值：

| 国家 | 默认时区 |
| --- | --- |
| 印尼 | `Asia/Jakarta` |
| 尼日利亚 | `Africa/Lagos` |

### 模板类型下拉与结构类型

素材组合结构类型使用 `MaterialTemplateTypeEnum` 表达，新增：

```java
LTO("LTO", "Limited-time offer template")
```

人工组合的【模板类型】下拉新增：

| 显示文案 | 提交值 | 说明 |
| --- | --- | --- |
| 普通模板 | `NORMAL` | 现有普通组合 |
| 轮播模板 | `CAROUSEL` | 现有轮播组合 |
| 限时优惠模板 | `LTO` | 新增；必须选择一个 LTO 素材 |

交互规则：

1. 选择 `普通模板` 时，展示 HEADER / BODY / FOOTER / BUTTONS，不展示 LTO 槽位。
2. 选择 `限时优惠模板` 时，展示 LTO 槽位，且必须选择一个 ACTIVE 的 LTO 素材。
3. 选择 `限时优惠模板` 后，编辑区不再展示 FOOTER 区域。
4. 选择 `限时优惠模板` 后，按 LTO 的 `hasExpiration` 校验 BUTTONS。
5. `LTO` 与 `CAROUSEL` 互斥；不支持 LTO 轮播模板。
6. 保存时，`ManualCombinationDTO.type = LTO`，并携带 `limitedTimeOfferMaterialRef`。

### LTO 组合结构约束

| 项 | 前端规则 |
| --- | --- |
| HEADER | 可选；HEADER 下拉只展示 `IMAGE` / `VIDEO` 素材，不展示 `TEXT` / `DOCUMENT` |
| BODY | 必填；未选择 BODY 时禁止保存并提示 |
| FOOTER | 不展示该区域；不做置灰交互 |
| BUTTONS | 按“限时优惠模板按钮校验规则”校验 `COPY_CODE` / `URL` 按钮类型和顺序 |

如果素材模板只有 TEXT HEADER，HEADER 选项为空，允许保存“无 HEADER”的 LTO 组合。

## 1.3 LTO 卡片操作

| 操作 | 行为 |
| --- | --- |
| 预览 | 右侧展示优惠文案、到期时间或倒计时，不调用发送接口（和当前预览效果一样） |
| 停止生成 | 复用现有 BODY 素材的停止生成逻辑 |
| 停用 | 复用现有素材停用逻辑；停用后不能被新组合选择 |

## 1.4 人工组合页

在【头部】和【内容】之间新增【限时优惠】下拉。

### 无 LTO 组合

```text
#1
* 模板类型：普通模板
头部：无HEADER
限时优惠：无 LTO
* 内容：内容
脚部：无FOOTER
```

### LTO 组合

```text
#1  [限时优惠]
* 模板类型：限时优惠模板
头部：无HEADER 或 图片 / 视频 HEADER
限时优惠：LTO-30分钟
* 内容：内容

> 说明：LTO 组合编辑区不展示 FOOTER。
```

### 联动规则

| 事件 | 前端处理 |
| --- | --- |
| 选择“无 LTO” | 恢复展示 FOOTER 区域，按普通组合校验 |
| 选择某个 LTO | 隐藏 FOOTER 区域，保存时 `footerMaterialRef` 置空 |
| LTO `hasExpiration=true` | 必须同时有 `COPY_CODE`、`URL` 按钮；顺序固定：`COPY_CODE` 第一位、`URL` 第二位 |
| LTO `hasExpiration=false` | 必须要有 `URL` 按钮；`COPY_CODE` 非必需；无 `COPY_CODE` 时 `URL` 第一位，有 `COPY_CODE` 时 `COPY_CODE` 第一位、`URL` 第二位 |
| LTO 已停用 | 下拉不可选，保存时报错 |

### 组合预览

```text
┌────────────────────────────────────┐
│ Offer ends soon                    │
│ ⏳ 有效期至：2026-09-10 12:00       │
│                                   │
│ Hi Tom, use code SAVE20           │
│ before it expires.                │
│                                   │
│ [Copy offer code]                 │
│ [Book now]                        │
└────────────────────────────────────┘
```

预览规则：

| 类型 | 预览展示 |
| --- | --- |
| ABSOLUTE | 展示 `expireAt + timezoneId` |
| RELATIVE | 展示“发送后 30 分钟内有效”，或本地模拟 `Date.now() + durationMillis` |

### BUTTONS 支持 COPY_CODE

当前素材模板页不支持配置 `COPY_CODE` 按钮，需要补充 BUTTONS 编辑能力。

按钮配置新增：

| 字段 | 控件 | 说明 |
| --- | --- | --- |
| 按钮类型 | Select | 支持 `URL`、`COPY_CODE` 等现有类型 |
| 示例优惠码 | Input | 仅 `COPY_CODE` 时展示，最大 15 字符 |
| 按钮顺序 | 列表排序 | 按 LTO 按钮规则：设置过期时间时有 `COPY_CODE` 第一位、`URL` 第二位；不设置过期时间且无 `COPY_CODE` 时 `URL` 第一位，有 `COPY_CODE` 时 `COPY_CODE` 第一位、`URL` 第二位 |

请求示例：

```json
{
  "buttons": {
    "type": "BUTTONS",
    "element": {
      "type": "BUTTONS",
      "buttons": [
        {
          "type": "COPY_CODE",
          "example": "SAVE20"
        },
        {
          "type": "URL",
          "text": "Book now",
          "url": "https://example.com/buy?code={{1}}",
          "example": "save20"
        }
      ]
    }
  }
}
```

三方通道均已支持：

| 通道 | 创建按钮 | 发送优惠码 |
| --- | --- | --- |
| YCLOUD | `COPY_CODE` | `coupon_code` |
| NXCLOUD | `copy_code` | `coupon_code` |
| GPI | `COPY_CODE` | `coupon_code` |

# 2. 前端组件与状态

## 2.1 组件拆分

| 组件 | 作用 |
| --- | --- |
| `LtoMaterialSection` | 素材模板页 LTO 区域容器 |
| `LtoMaterialCard` | 单个 LTO 素材卡片 |
| `LtoMaterialForm` | LTO 新增 / 编辑表单 |
| `LtoPreviewModal` | LTO 预览弹窗 |
| `ComboLtoSelect` | 人工组合页 LTO 下拉 |
| `ComboTemplatePreview` | 组合模板预览，增加 LTO 渲染区域 |

## 2.2 核心状态

```ts
interface LtoExpirationPolicy {
  type: 'ABSOLUTE' | 'RELATIVE';
  expireAt?: string;
  expireAtMs?: number;
  timezoneId?: string;
  countryCode?: string;
  sourceExpression?: string;
  durationMillis?: number;
}

interface LtoElement {
  type: 'LIMITED_TIME_OFFER';
  limited_time_offer: {
    text: string;
    has_expiration: boolean;
    expirationPolicy?: LtoExpirationPolicy;
  };
}

interface LtoMaterialItem {
  tempKey?: string;
  id?: string;
  materialGroupId?: number;
  status: 'ACTIVE' | 'PAUSED' | 'DELETED';
  type: 'LIMITED_TIME_OFFER';
  subType: 'NONE';
  element: LtoElement;
}
```

新增 LTO 时，前端生成本地 `tempKey`，用于同一请求内新建素材和新建组合的临时引用：

```ts
const tempKey = `lto_temp_${Date.now()}_${Math.random().toString(16).slice(2)}`;
```

人工组合状态：

```ts
interface ManualCombination {
  templateType: 'NORMAL' | 'CAROUSEL' | 'LTO';
  headerMaterialRef?: string;
  limitedTimeOfferMaterialRef?: string;
  bodyMaterialRef: string;
  footerMaterialRef?: string;
  buttonsMaterialRef?: string;
  status: 'ACTIVE' | 'INACTIVE';
}
```

## 3.5 现有素材操作

【停止生成】和【停用 / 启用】复用现有素材操作逻辑，不新增 LTO 专用接口。

# 4. 校验与异常

| 场景 | 提示 |
| --- | --- |
| 优惠文案为空 | `请输入优惠文案` |
| 优惠文案超过 16 字符 | `优惠文案不能超过 16 个字符` |
| ABSOLUTE 未选时间 | `请选择到期时间` |
| ABSOLUTE 时间早于当前时间 | `到期时间必须晚于当前时间` |
| ABSOLUTE 未选时区 | `请选择时区` |
| RELATIVE 时长为空 | `请输入有效时长` |
| RELATIVE 时长 <= 0 | `时长必须大于 0` |
| 组合选择 LTO 且仍提交 FOOTER | `限时优惠模板不支持 FOOTER` |
| LTO 组合 HEADER 类型非法 | `限时优惠模板 HEADER 仅支持图片或视频` |
| LTO 组合缺少 BODY | `限时优惠组合必须选择内容素材` |
| 缺少 `URL` 按钮 | `限时优惠组合必须包含访问网址（URL）按钮` |
| LTO `hasExpiration=true` 且无按钮素材 | `展示到期时间的限时优惠组合必须选择按钮素材` |
| `COPY_CODE` 不在第一位 | `限时优惠组合的第一个按钮必须为 COPY_CODE` |
| `URL` 不在第二位 | `限时优惠组合的第二个按钮必须为访问网址（URL）` |
| 无 `COPY_CODE` 时 `URL` 不在第一位 | `限时优惠组合的第一个按钮必须为访问网址（URL）` |
| COPY_CODE.example 为空 | `COPY_CODE 示例优惠码不能为空` |
| 优惠码超过 15 位 | `优惠码不能超过 15 个字符` |

后端错误按通用结构展示：

```json
{
  "code": "LTO_COPY_CODE_NOT_FIRST",
  "message": "限时优惠组合的第一个按钮必须为 COPY_CODE"
}
```

# 5. 联调与验收

## 5.1 联调顺序

1. 素材模板创建：新增 LTO 素材并保存。
2. 素材模板详情：刷新后回显 `limitedTimeOfferList`。
3. 人工组合：选择 LTO 并保存。
4. 组合查询：确认返回 `limitedTimeOfferMaterialId`。
5. 正式模板创建：确认 `components` 包含 LTO。
6. 后端创建通道模板：确认内部 `expirationPolicy` 不透传。

## 5.2 前端验收点

### 素材模板页

- [ ] LTO 区域位于模板头部和模板内容之间。
- [ ] 支持添加多个 LTO。
- [ ] 支持 LTO 预览、停止生成、停用。
- [ ] 优惠文案最大 16 字符。
- [ ] ABSOLUTE 必须选择未来时间和时区。
- [ ] RELATIVE 必须大于 0。
- [ ] 编辑时能正确回显 ABSOLUTE / RELATIVE。

### 人工组合页

- [ ] LTO 槽位位于头部和内容之间。
- [ ] 默认“无 LTO”。
- [ ] 选择 LTO 后不展示 FOOTER，且不提交 `footerMaterialRef`。
- [ ] HEADER 下拉只展示 `IMAGE` / `VIDEO`。
- [ ] LTO 组合未选择 BODY 时无法保存。
- [ ] 支持配置 `COPY_CODE`、`URL` 按钮和示例优惠码。
- [ ] 设置过期时间时，强制 `COPY_CODE` 第一位、`URL` 第二位。
- [ ] 不设置过期时间时，必须有 `URL`；无 `COPY_CODE` 时 `URL` 第一位，有 `COPY_CODE` 时 `COPY_CODE` 第一位、`URL` 第二位。
- [ ] 取消 LTO 后恢复 FOOTER 可选。
- [ ] 保存请求携带正确的 `limitedTimeOfferMaterialRef`。

### 正式模板

- [ ] `components` 包含 `LIMITED_TIME_OFFER`。
- [ ] 无 LTO 组合生成的模板不包含 LTO。
- [ ] LTO 组件字段与接口示例一致。

## 5.3 回归点

| 场景 | 期望 |
| --- | --- |
| 旧素材模板无 LTO | 页面和保存行为不变 |
| 旧人工组合无 LTO | 正式模板生成行为不变 |
| OTP 模板 | 不受影响 |
| UTILITY 模板 | 不受影响 |
| 普通 MARKETING 模板 | 不受影响 |
| COPY_CODE 但无 LTO | 现有逻辑不变 |
