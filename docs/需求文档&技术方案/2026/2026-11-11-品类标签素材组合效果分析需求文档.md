# 品类、标签、素材组合效果分析需求文档

> 日期：2026-11-11  
> 文档状态：需求设计稿

## 一、背景与建设目标

素材已经具备品类、标签和素材组合模板等结构化信息，发送统计、触达统计和业务转化统计也已经分别沉淀。当前缺少一个统一页面，把这些数据按照品类、标签和素材组合模板组织起来，用户无法快速回答以下问题：

- 不同品类下的素材组合模板分别产生了多少发送、送达、已读、点击和业务转化数据；
- 一个标签覆盖了哪些素材组合模板，这些组合在指定时间和归因窗口内表现如何；
- 某个素材组合模板的效果来自哪些日期、任务、泳道和业务场景；
- 当前数据是否已经完整，哪些指标仍未接入或仍在观察窗口内。

本需求建设一套素材效果分析页面，目标是让用户能够先查看完整可用数据，再自行选择指标和分析维度，逐步从品类、标签或素材组合模板下钻到日期、任务、泳道和业务场景，形成可复核的数据结果和后续观察建议。

页面需要具备以下能力：

1. 按品类、标签、素材组合模板查看效果数据；
2. 自主选择需要查看的指标和归因窗口；
3. 按日期、素材包、任务、泳道、业务场景和数据来源筛选；
4. 查看汇总结果并下钻到具体素材组合模板和来源明细；
5. 区分 AI 标签和用户选择标签；
6. 区分当前生效品类和 AI 候选品类；
7. 对缺失数据、未接入数据和观察窗口未完成的数据给出明确状态；
8. 导出当前筛选结果及其统计口径。

## 二、分析对象、来源与指标范围

### 2.1 分析对象

本页面提供三个平行的分析对象：

| 分析对象 | 说明 | 页面用途 |
|---|---|---|
| 品类 | 素材或素材组合模板的当前生效品类 | 查看不同品类的指标分布，并下钻到组合 |
| 标签 | 素材绑定的全局标签 | 查看标签覆盖的素材组合及其效果 |
| 素材组合模板 | 由多个素材组件组成的可投放组合 | 查看最细的组合效果，并继续查看日期、任务和泳道 |

品类和标签是两个独立维度。一个全局标签可以被不同品类的素材使用，一个素材组合模板也可以关联多个标签。标签可以作为独立入口，也可以和品类组合筛选。

### 2.2 品类与标签来源

页面需要把来源信息作为数据属性展示，避免用户误解不同来源的数据含义。

| 对象 | 页面展示范围 | 来源说明 |
|---|---|---|
| 当前生效品类 | 当前用于素材和组合模板的品类 | 以素材实际品类或组合品类快照为准 |
| AI 候选品类 | AI 分析出的、尚未作为当前生效品类使用的品类 | 单独展示，不覆盖当前生效品类 |
| AI 标签 | AI 根据素材内容生成的标签绑定 | 用于按内容特征查看素材分布 |
| 用户选择标签 | 用户配置素材时选择的标签绑定 | 用于按用户定义的业务特征查看素材分布 |
| 编码规则标签 | 由结构化规则生成的特征标签 | 作为后续扩展规划，本次不作为已交付数据 |

标签来源以具体素材绑定记录的来源为准。同一个标签名称可以出现在不同来源下，页面按来源分别展示，不将不同来源的标签直接做优劣比较。

当前生效品类和 AI 候选品类可以区分；如果后续要求精确展示“当前生效品类由用户选择还是由 AI 写入”，需要补充品类赋值来源记录，当前页面不根据品类字典来源推断赋值来源。

### 2.3 指标范围

页面提供完整指标池，用户可以根据分析目的选择需要展示的指标。

| 指标类别 | 指标 |
|---|---|
| 请求与发送 | 请求量、发送量 |
| 触达 | 送达量、送达率 |
| 阅读 | 已读量、已读率 |
| 互动 | 点击量、点击率、Flow 提交量、回复量 |
| 用户反馈 | 退订量、投诉量 |
| 业务转化 | 注册量、申请授信量、放款量 |

业务场景、任务和泳道作为筛选与拆分维度，帮助用户限定数据范围和理解结果。页面按照用户选择的指标展示数据，完整保留数据源已经提供的指标。

本次不纳入 OTP 的回填率分析；当前没有回款数据时，页面不使用放款量代替回款量。

## 三、页面产出

### 3.1 页面整体布局

页面由筛选区、指标概览区、分析视图区和明细下钻区组成：

```text
┌──────────────────────────────────────────────────────────────────────────────┐
│ 素材效果分析       数据截止：2026-11-03       更新时间：2026-11-04 09:30      │
├──────────────────────────────────────────────────────────────────────────────┤
│ 日期范围 │ 数据来源 │ 归因窗口 │ 品类 │ 标签 │ 任务 │ 泳道 │ 业务场景 │ 查询 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 指标选择：发送  送达率  已读率  点击率  注册  申请授信  放款  ...             │
├──────────────────────────────────────────────────────────────────────────────┤
│ 发送量       送达率       已读率       点击率       放款事件/送达              │
├──────────────────────────────────────────────────────────────────────────────┤
│ [品类视图] [标签视图] [素材组合模板视图]                                      │
│ 分组名称 │ 命中组合数 │ 发送 │ 送达率 │ 已读率 │ 点击率 │ 放款事件/送达 │ 下钻 │
├──────────────────────────────────────────────────────────────────────────────┤
│ 选中分组详情：趋势图、组合列表、任务/泳道分布、指标口径、数据状态             │
└──────────────────────────────────────────────────────────────────────────────┘
```

### 3.2 筛选区

筛选区包含：

- 日期范围；
- 数据来源：业务统计、渠道统计；
- 归因窗口：T1、T3、T7；
- 品类；
- 标签及标签来源；
- 标签状态：正式、AI 候选；
- 素材包；
- 素材组合模板；
- 任务；
- 泳道；
- 业务场景（取任务 `SCENARIO` 标签原始 value）；
- 指标选择。

不同数据来源能够提供的维度不同，页面需要在筛选项旁展示可用范围。用户选择了某个筛选条件后，结果区域显示实际命中的数据量和数据状态。

### 3.3 三个分析视图

**品类视图**展示每个品类的指标结果、命中素材组合模板数量和样本量，点击某个品类后进入组合明细。

**标签视图**展示标签名称、标签来源、标签状态、命中素材数、命中组合数和指标结果。标签可以跨品类查看，也可以继续选择某个品类、任务或泳道。

**素材组合模板视图**展示素材组合模板、所属品类、关联标签、日期、任务、泳道、归因窗口和完整指标。该视图是最细的页面结果，可以打开明细抽屉查看来源记录。

### 3.4 结果和建议

页面输出以下内容：

- 各分组的原始计数和派生比率；
- 分子、分母和样本数量；
- 命中的素材组合模板数量；
- 日期趋势；
- 任务、泳道和业务场景分布；
- 数据来源、数据截止日期和更新时间；
- T1/T3/T7 当前窗口状态；
- 缺失数据、未接入数据和观察中数据提示；
- 当前筛选结果导出文件；
- 当前分组对应的来源明细列表和来源明细导出文件；
- 汇总结果导出接口和来源明细导出接口。

结果摘要以数据事实和后续观察方向为主，例如：

> “平和”标签当前命中 12 个素材组合模板，其中 8 个属于首贷类、4 个属于还款提醒类。在当前日期范围和 T7 窗口内，首贷类和还款提醒类的指标分布不同，建议分别查看对应组合和任务明细。

页面不自动将某个品类、标签或组合判定为业务因果结论。放款量表示放款事件次数，不能解释为回款量或去重用户数。

## 四、统计口径与结果使用

### 4.1 指标口径

- 送达率 = 送达量 ÷ 发送量；
- 已读率 = 已读量 ÷ 送达量；
- 点击率 = 点击量 ÷ 送达量；
- 注册率 = 注册量 ÷ 送达量；
- 申请授信率 = 申请授信量 ÷ 送达量；
- 放款事件/送达 = 放款事件次数 ÷ 送达量；
- 已读率的分母使用送达量，与素材组合页面的 `readRate` 口径一致；
- 注册、申请授信、放款按事件次数展示；
- T1、T3、T7 分开查看，不将不同窗口直接相加；
- 分母为 0 时显示“—”；
- 数据没有接入时显示“未接入”；
- 归因窗口未完成时显示“观察中”；
- 0 表示数据源明确返回 0，不能用 0 代替缺失数据。

### 4.2 标签统计

标签按“含该标签素材所参与消息的整体效果”统计。一个素材组合模板中的多个组件命中同一标签时，该标签在该组合内只计一次。多个标签的命中组合可以重叠，页面不能把不同标签结果相加作为整体总量。

默认统计正式标签；AI 候选标签可以通过单独的筛选条件查看。AI 标签和用户选择标签分别展示，不比较不同来源的标签准确性或优劣。编码规则标签作为后续扩展，不纳入本期统计。

### 4.3 结果使用

用户可以采用以下分析顺序：

1. 选择时间范围、数据来源和归因窗口；
2. 选择一个或多个指标；
3. 从品类、标签或素材组合模板视图开始查看；
4. 继续按任务、泳道、业务场景和日期拆分；
5. 打开组合来源明细，核对数据范围和统计口径；
6. 导出当前结果，作为后续素材验证、投放调整或数据补充的依据。

页面展示的是当前筛选范围内的事实数据和可继续观察的对象。用户可以根据结果形成后续假设，但页面不直接把相关性结论写成因果结论。

## 五、验收标准与后续扩展

### 5.1 验收标准

- 用户可以直接进入品类、标签或素材组合模板视图；
- 页面可以选择指标和 T1/T3/T7 归因窗口；
- 品类和标签可以独立筛选，也可以组合筛选；
- 页面可以区分 AI 标签和用户选择标签；
- 页面可以区分当前生效品类和 AI 候选品类；
- 页面可以按日期、素材包、任务、泳道和业务场景筛选；
- 页面可以从品类或标签下钻到素材组合模板；
- 页面可以从品类、标签或素材组合模板下钻到素材组合模板；
- 页面可以查看并导出当前组合对应的来源统计明细；
- 品类和标签分组下钻时，系统将命中的组合模板集合传递给来源明细查询。
- 同一个组合命中同一个标签多次时不会重复计数；
- T1、T3、T7 可以单独查看；
- 缺失数据、未接入数据、0 值和观察中数据能够区分；
- 页面展示指标的分子、分母、数据来源和数据截止日期；
- 当前汇总结果可以导出；
- 当前来源明细可以单独导出；
- OTP 回填率和编码规则标签保持后续扩展范围。

### 5.2 后续扩展

- 保存素材品类赋值来源，支持区分用户选择品类和 AI 生成品类；
- 增加编码规则标签的生成、存储、版本和统计能力；
- 接入回款事件后增加还款量、回款率等指标；
- 根据用户反馈增加常用指标组合和分析模板；
- 增加标签历史版本，支持按发送时的标签状态回看历史数据。
