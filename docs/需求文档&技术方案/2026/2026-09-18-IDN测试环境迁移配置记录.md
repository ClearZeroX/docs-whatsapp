### 4. Redis 类型判断

新 Redis 只提供了一个地址和端口，并且明确使用 `database=1`。

标准 Redis Cluster 只支持 `database=0`，所以新 Redis 大概率不是标准 Redis Cluster，更可能是：

- 单机 Redis
- 主从 Redis
- 云 Redis 代理模式

因此先按单地址模式配置：

```yaml
spring:
  redis:
    host: redis-mlynamc1nuou1726q.redis.ibytepluses.com
    port: 6379
    password: CcONgb4EAouIzXOC
    database: 1
```

### 5. 代码适配结论

不需要修改 Java 代码。

项目通过 `redisson-spring-boot-starter` 自动读取 `spring.redis` 配置，业务代码统一使用：

- `StringRedisTemplate`
- `RedisTemplate`
- `RedissonClient`

Redis 地址、密码、database 都通过 Apollo 配置生效。
