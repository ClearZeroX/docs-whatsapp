# AI 备用素材模版 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 基于 `AI_BACKUP_MATERIAL_GROUP` 建设 AI 备用素材模版生成、状态查询、同步创建、编辑联动与补偿能力，并移除未上线的泳道/MQ 创建依赖。

**Architecture:** 以 `ai_material_suggestion` 存储 AI 备用素材生成结果，以 `message_material_group.ai_suggest_type` 标识 AI 备用素材模版，以 `primary_combination_id` 关联主素材组合和 AI 备用素材组合。前端通过 `batchGenerate` 异步触发批量 AI 生成，通过专用 status 接口判断结果；后端创建/更新主素材模版后在事务提交后同线程同步尝试创建/更新 AI 备用素材模版，异常降级不影响主流程。

**Tech Stack:** Java 8, Spring Boot 2.2.6, MyBatis-Plus, Fastjson, Apollo, MongoDB, Redis, XXL-Job, JUnit 5, Mockito, Maven multi-module.

```java
private AiMaterialSuggestion latestUsableSuccess(List<AiMaterialSuggestion> records) {
    if (CollectionUtils.isEmpty(records)) {
        return null;
    }
    return records.stream()
            .filter(r -> AiMaterialSuggestionStatusEnum.ACCEPTED_FOR_AI_BACKUP.getCode() == r.getStatus())
            .filter(r -> StringUtils.isNotBlank(r.getSuggestedContent()))
            .filter(r -> !AiMaterialSuggestionConstants.GENERATION_FAILED_CONTENT.equals(r.getSuggestedContent()))
            .sorted(this::compareSuggestionDesc)
            .findFirst()
            .orElse(null);
}

private AiMaterialSuggestion latestBySeqCreateTimeId(List<AiMaterialSuggestion> records, int status) {
    if (CollectionUtils.isEmpty(records)) {
        return null;
    }
    return records.stream()
            .filter(r -> r.getStatus() != null && r.getStatus() == status)
            .sorted(this::compareSuggestionDesc)
            .findFirst()
            .orElse(null);
}

private int compareSuggestionDesc(AiMaterialSuggestion a, AiMaterialSuggestion b) {
    int seq = Comparator.nullsLast(Integer::compareTo).compare(b.getGenerationSeq(), a.getGenerationSeq());
    if (seq != 0) {
        return seq;
    }
    int createTime = Comparator.nullsLast(Long::compareTo).compare(b.getCreateTime(), a.getCreateTime());
    if (createTime != 0) {
        return createTime;
    }
    return Comparator.nullsLast(Long::compareTo).compare(b.getId(), a.getId());
}
```

```java
private List<AiMaterialSuggestion> queryLatestAcceptedSuggestions(Long primaryGroupId, String aiSuggestType) {
    List<AiMaterialSuggestion> records = aiMaterialSuggestionMapper.selectList(
            new LambdaQueryWrapper<AiMaterialSuggestion>()
                    .eq(AiMaterialSuggestion::getMaterialGroupId, primaryGroupId)
                    .eq(AiMaterialSuggestion::getSuggestType, aiSuggestType)
                    .eq(AiMaterialSuggestion::getStatus, AiMaterialSuggestionStatusEnum.ACCEPTED_FOR_AI_BACKUP.getCode())
    );
    if (CollectionUtils.isEmpty(records)) {
        return Collections.emptyList();
    }
    return records.stream()
            .filter(r -> StringUtils.isNotBlank(r.getClientMaterialKey()))
            .filter(r -> StringUtils.isNotBlank(r.getSuggestedContent()))
            .filter(r -> !AiMaterialSuggestionConstants.GENERATION_FAILED_CONTENT.equals(r.getSuggestedContent()))
            .collect(Collectors.groupingBy(AiMaterialSuggestion::getClientMaterialKey))
            .values()
            .stream()
            .map(list -> list.stream().sorted(this::compareSuggestionDesc).findFirst().orElse(null))
            .filter(Objects::nonNull)
            .collect(Collectors.toList());
}
```
