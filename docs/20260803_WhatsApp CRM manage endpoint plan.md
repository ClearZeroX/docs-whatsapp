## 二、架构优化：管理端"生产流水线"闭环

### 2.1 现状痛点

当前管理端各模块是"烟囱式"的——运营在素材页管素材、在模板页管模板、在任务页管任务，三者之间没有一条可视化的流转链路。

### 2.2 设计方案

建立一条从前到后的生产流水线，核心是**上下游关联 + 影响面感知 + 健康度大盘**：

```
素材库 → 素材组 → 素材组合 → 模板 → 任务 → 健康度大盘
```

### 2.3 三个具体落地点

#### 1. 上下游关联视图

在素材组详情页能看到关联了哪些模板 → 模板关联了哪些任务 → 任务发送数据。在模板页能看到上游素材组合 → 下游任务列表。运营操作某个环节时能感知对上下游的影响。

> 小细节：`message_template.material_group_id` 和 `material_combination_id` 字段已有，`task_base.message_template_id` 也有了下游关联，补充前端展示 + 一个"影响面分析"接口即可。

#### 2. 变更影响预警

当素材被删除/下线、模板被 Meta 降级为 MARKETING、WABA 实例被禁用时，主动通知关联的素材组和任务负责人。

> 小细节：当前模板伪装建议（`TemplateDisguiseSuggestion`）已做到"模板被降级后通知运营"，可扩展为通用的"变更影响通知"机制。

#### 3. 生产健康度大盘

把现有的分散统计（模板稳定性统计、素材组可用统计、任务发送统计）统一汇总到一个页面，让运营一眼看到当前生产线的整体健康状态。

> 小细节：`batchFillMaterialTemplateStabilityStat` 和 `MaterialGroupStabilityService` 已在做这方面工作，收拢到统一的 Dashboard 接口。

## 三、架构优化：管理端操作审计与版本追溯

### 3.1 第一层：操作审计日志

所有管理端"写"操作（创建/编辑/删除/上线/下线）统一记录到审计日志，包含操作人、操作类型、操作对象、变更内容（JSON diff）、操作时间。

> 小细节：`DataChangeLogService` 已有雏形，只需补齐所有管理端 Controller 的切面接入 + 变更内容自动生成 JSON diff + 前端"操作日志"查询页。

### 3.2 第二层：模板版本管理

模板是核心资产，每次修改自动保存版本快照，支持版本对比和回滚。

> 小细节：新增 `message_template_version` 表，包含 `template_id`、`version`、`components_snapshot`、`creator`、`ctime`。

## 四、AI 增强：管理端智能能力升级

基于项目已有的 AI 基础设施（Solon ReActAgent、模板伪装、稳定性分析、素材 RAG、文案生成），在管理端各环节嵌入 AI 能力。

### 4.1 模板伪装建议闭环

当前已做到"检测 → 生成建议"，下一步形成闭环：**检测 → 建议 → 一键应用 → 效果追踪**，让运营能直接采纳 AI 建议并看到采纳后的效果。

> 小细节：`TemplateDisguiseSuggestion` 表已预留 `status`、`feedbacks` 字段，补齐前端交互即可。

### 4.2 AI 模板质量预检

模板提交到 Meta 审核前，用 LLM 预判通过率，指出可能被拒的内容（营销词、链接类型、格式问题），减少审核驳回次数。

> 小细节：复用模板稳定性分析 Agent 的 components 分析能力，换个 prompt 方向即可。

### 4.3 创建模板时一键 AI 优化

运营填写模板内容后，点击"AI 优化"，自动检查并优化：文案去营销化、格式合规检查、多语言翻译质量检查、图片/按钮配置建议。降低运营手动调整成本，提升模板一次审核通过率。

> 小细节：复用 `MarketingCopyWritingGeneratorService` 和模板稳定性分析能力，串联为一个优化 pipeline。

### 4.4 任务备用素材自动生成

当任务使用的素材模板因审核被拒、下线或质量降级，需要切换到备用素材组合时，AI 自动基于任务上下文（目标人群、历史效果、素材库）生成新的素材组合建议，减少人工应急配置时间。

> 小细节：结合 `MaterialRAGService` 素材检索 + `PictureGeneratorService` 图片生成 + `MarketingCopyWritingGeneratorService` 文案生成，串成一个自动补位 pipeline。

### 4.5 素材智能标签 + 推荐

素材库中的图片/文案用 AI 自动打标签（场景、风格、色调），运营做模板时根据标签推荐匹配素材，减少人工翻找素材的时间。

> 小细节：`MaterialAITagService` 和 `VikingDBService`（向量库）已有基础设施，补齐标签体系 + 推荐接口即可。
