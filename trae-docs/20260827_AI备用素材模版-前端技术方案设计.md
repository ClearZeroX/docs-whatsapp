# AI 备用素材模版勾选功能

## 1. 功能概述

在素材模板编辑页面的 AI 内容建议区域，新增运营勾选功能，用于控制是否将 AI 生成的内容作为 AI 备用素材模版。

### 1.1 核心设计原则

- **新建阶段**：勾选仅记录用户意图，不实时调用后端接口，可随时修改
- **提交时**：对有勾选的 body 调用 `batchGenerate` 接口，然后提交素材模版
- **编辑/查看回显**：调用 `status` 接口（`materialIdList`）还原勾选状态

### 1.2 交互逻辑表

| 操作 | 结果 |
|------|------|
| 新建阶段勾选"接受所有body" | 不禁用单body勾选，可随时修改为单body勾选，**不调用后端**，不禁用+添加 |
| 新建阶段勾选"接受该body" | 仅标记当前body，**不调用后端** |
| 新建阶段取消勾选 | 可随时修改，**不调用后端** |
| 新增body — 编辑阶段（回显"接受所有"） | 新body默认勾选"接受所有body"；回显为部分时，新body不勾选 |
| 点击"更多"展开 | 调用 `generate`（不传泳道），仅生成一次，展示建议 + 评分 + `☐ 拒绝` |
| 点击"成本优先AI建议" | 展开实时AI建议区域（按泳道、多轮）—— 与"更多"展开互不影响 |
| 提交 — 三选一未勾选 | 弹窗提示，阻止提交 |
| 提交 — 有勾选 | 对勾选的body调用 `batchGenerate`，然后提交素材模版 |
| 编辑/查看回显 | 调 status 接口（`materialIdList`），totalCount === successCount → 勾选"接受所有"；部分 → 除NOT_ACCEPTED_FOR_AI_BACKUP外都回显"接受该body" |
| 编辑提交 | 对新增body调用 `batchGenerate`，然后提交更新 |

#### 3.3.3 编辑/查看回显

```javascript
async loadBackupMaterialStatus() {
  if (!this.materialGroupId || this.pageType === 'add') return;
  
  const materialIdList = this.bodyList.map(item => item.id).filter(Boolean);
  if (materialIdList.length === 0) return;
  
  const res = await backupMaterialStatus({
    materialGroupId: this.materialGroupId,
    materialIdList,
  });
  
  if (res.code === 200 && res.data) {
    const { totalCount = 0, successCount = 0 } = res.data;
    const allDone = totalCount > 0 && totalCount === successCount;
    if (allDone) {
      // totalCount === successCount → 勾选"接受所有"
      this.acceptAll = true;
      materialIdList.forEach(materialId => {
        this.bodyAcceptanceStatus[materialId] = 'acceptAll';
      });
    } else {
      // 部分body → 除NOT_ACCEPTED_FOR_AI_BACKUP外都回显"接受该body"
      res.data.items.forEach(item => {
        if (item.status !== 'NOT_ACCEPTED_FOR_AI_BACKUP') {
          this.bodyAcceptanceStatus[item.materialId] = 'acceptThis';
        }
      });
    }
  }
}
```

#### 3.3.4 提供给父组件的方法

```javascript
// 获取勾选的body列表（供提交使用）
getCheckedBodies() {
  return Object.entries(this.bodyAcceptanceStatus)
    .filter(([_, status]) => status !== null && status !== 'refuseThis')
    .map(([key]) => key);
},

// 获取新增body列表（编辑提交使用）
getNewBodyKeys() {
  return this.bodyList
    .filter(item => !item.id)  // 没有 mongo id 即为新增
    .map((_, i) => this.getClientKey(i));
},
```

### 3.4 TemplateAction.vue 改动

#### 3.4.1 提交前校验

```javascript
async handleSubmit() {
  // ... 现有校验 ...
  
  // 校验备用素材模版勾选
  const checkedBodies = this.$refs.templateContent?.getCheckedBodies();
  const hasAnyChecked = checkedBodies && checkedBodies.length > 0;
  
  // 检查是否有"更多"展开中勾选了"拒绝"
  const hasRefused = this.$refs.templateContent?.hasAnyRefused();
  
  if (!hasAnyChecked && !hasRefused) {
    // 三选一都没勾选 → 弹窗提示
    await this.$alert(
      this.$t('aiSuggestion.backupMaterialRequired'),
      this.$t('common.tip'),
      { confirmButtonText: this.$t('common.confirm') }
    );
    return;
  }
  
  // 有勾选 → 调用 batchGenerate
  if (hasAnyChecked) {
    try {
      await batchGenerate({
        clientMaterialKeys: checkedBodies,
        suggestType: 'AI_BACKUP_MATERIAL_GROUP',
        // ... 其他参数
      });
    } catch (e) {
      console.error('batchGenerate failed:', e);
      // 不阻塞提交
    }
  }
  
  // 继续提交
  this.doSubmit();
}
```

### 3.5 API 新增

```javascript
// src/api/aiSuggestion.js

// Batch generate AI backup material suggestions (async)
export function batchGenerate(data) {
  return request({
    url: `${BASE}/batchGenerate`,
    method: "post",
    data,
  });
}

// Query backup material generation status
// 入参: { materialGroupId?, materialIdList: string[] }
export function backupMaterialStatus(data) {
  return request({
    url: `${BASE}/backup-material/status`,
    method: "post",
    data,
  });
}
```

## 4. 数据流图

```
新建模式
  │
  ├─ 勾选"接受所有body" ──→ 仅标记状态，不调后端
  ├─ 勾选"接受该body"   ──→ 仅标记状态，不调后端
  ├─ 新增body（"接受所有"已勾选）──→ 继承"接受所有"状态（新建阶段）
  ├─ 点击"更多"展开     ──→ generate(不传泳道) ──→ 同步返回建议
  │                                                    │
  │                                                    └─→ ☐ 拒绝该body
  │
  └─ 提交 ──→ 三选一未勾选? ──→ 弹窗提示
             └─→ 有勾选 ──→ batchGenerate(勾选body) ──→ 提交素材模版

编辑/查看模式
  │
  ├─ 回显 ──→ status(materialIdList) ──→ totalCount===successCount? ──→ 勾选"接受所有"
  │                                                  │
  │                                                  └─→ 部分 ──→ 除NOT_ACCEPTED_FOR_AI_BACKUP外回显"接受该body"
  │
  └─ 编辑提交 ──→ 有新增body? ──→ batchGenerate(新增body) ──→ 提交更新
```

## 6. 与现有功能的关系

| 现有功能 | 影响 |
|---------|------|
| 实时 AI 建议（成本优先/通用） | 不受影响，独立展开收起 |
| 泳道选择 | 实时AI建议仍按泳道生成；更多展开不区分泳道 |
| 反馈重新生成 | 仅实时AI建议可用；更多展开区域不支持 |
| 评分 | 两者都支持 |
| 添加 body | "接受所有"勾选后不禁用，新增body默认继承 |
| 编辑/查看回显 | 新增 status 接口回显逻辑（materialIdList） |
| 提交流程 | 新增 batchGenerate 前置调用 |
