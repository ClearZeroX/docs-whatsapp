# AI备用素材模版勾选与提交二次确认功能

## 1. 功能概述

在 AI 内容建议面板中新增"接受本次AI生成内容生成AI备用素材模版"复选框，并在提交模板时增加校验逻辑：

- 用户可选择是否接受 AI 生成内容作为备用素材模版
- 勾选后，"根据反馈重新生成"按钮不可用；不勾选时，反馈输入框必填
- 提交时校验：未生成过 AI 建议 → 阻止提交；已生成但无勾选 → 二次确认弹窗
- 通过 `VUE_APP_CHANNEL` 环境变量控制功能按国家/地区显隐（当前仅印尼 INA 显示，尼日利亚 NG 隐藏）

---

## 2. 环境/国家显隐控制

### 2.1 机制

项目通过构建时环境变量 `VUE_APP_CHANNEL` 区分国家，取值：

| 值 | 国家 | .env 文件 | 构建命令 |
|----|------|-----------|---------|
| `INA` | 印度尼西亚 | `.env.ina` / `.env.production` / `.env.testina` / `.env.development` | `build:ina` / `build:prod` / `build:testina` / `dev` |
| `NG` | 尼日利亚 | `.env.em` / `.env.okash` / `.env.opay` / `.env.testem` / `.env.testok` / `.env.testopay` | `build:em` / `build:okash` / `build:opay` / `build:testem` / `build:testok` / `build:testopay` |

### 2.2 显隐策略

| 组件/逻辑 | INA（印尼） | NG（尼日利亚） |
|-----------|------------|--------------|
| AI 建议面板（AiSuggestionPanel） | **显示** | **隐藏**（`v-channel="'INA'"` 移除 DOM） |
| 提交前 AI 校验（validateAiSuggestion） | **执行** | **跳过**（`VUE_APP_CHANNEL !== 'INA'` 提前返回） |

### 2.3 尼日利亚上线步骤

当尼日利亚后端 AI 建议接口就绪后，按以下步骤开启：

1. **移除 `v-channel` 指令**：删除 TemplateContent.vue 中 `AiSuggestionPanel` 上的 `v-channel="'INA'"`
2. **移除 channel 校验**：删除 TemplateAction.vue 中 `validateAiSuggestion()` 方法的 `VUE_APP_CHANNEL !== 'INA'` 提前返回

## 4. 交互逻辑表

| 复选框状态 | 反馈输入框 | 重新生成按钮 | 说明 |
|-----------|-----------|-------------|------|
| ☐ 未勾选 + 空 | — | **禁用** | 不接受则必须提供反馈 |
| ☐ 未勾选 + 已填 | 必填 | **可用** | 可根据反馈重新生成 |
| ☑ 已勾选 | 可选 | **禁用** | 接受后不再重新生成 |
| 重新生成后 | 新内容默认 ☐ | 同上规则 | 新内容独立判断 |

#### 5.3.2 新增方法

```javascript
// Handle acceptance change from AiSuggestionPanel
handleAcceptanceChange(bodyIndex, { suggestionId, accepted }) {
  this.$emit('acceptance-change', { bodyIndex, suggestionId, accepted });
},

// Check if any body has generated AI suggestions
hasGeneratedSuggestions() {
  const panels = this.$refs.aiSuggestionPanels;
  if (!panels) return false;
  const panelList = Array.isArray(panels) ? panels : [panels];
  return panelList.some(p => p.hasGenerated && p.hasGenerated());
},

// Check if any body has accepted suggestions
hasAnyAccepted() {
  const panels = this.$refs.aiSuggestionPanels;
  if (!panels) return false;
  const panelList = Array.isArray(panels) ? panels : [panels];
  return panelList.some(p => p.hasAnyAccepted && p.hasAnyAccepted());
},
```

#### 5.4.3 新增方法

```javascript
// Validate AI suggestion before submit
async validateAiSuggestion() {
  // Skip AI validation for non-INA channels
  if (process.env.VUE_APP_CHANNEL !== 'INA') {
    return true;
  }

  const contentRef = this.$refs.templateContent;
  if (!contentRef) return true;

  const hasGenerated = contentRef.hasGeneratedSuggestions();

  // Scenario 1: Never generated AI suggestions
  if (!hasGenerated) {
    await this.$alert(
      this.$t('aiSuggestion.pleaseUseAiFirst'),
      this.$t('common.hint'),
      { confirmButtonText: this.$t('common.confirm'), type: 'warning' }
    );
    return false;
  }

  // Scenario 2: Has generated but no accepted
  const hasAccepted = contentRef.hasAnyAccepted();
  if (!hasAccepted) {
    try {
      await this.$confirm(
        this.$t('aiSuggestion.noAcceptedConfirm'),
        this.$t('common.hint'),
        {
          confirmButtonText: this.$t('aiSuggestion.goSelect'),
          cancelButtonText: this.$t('aiSuggestion.submitAnyway'),
          distinguishCancelAndClose: true,
          type: 'warning',
        }
      );
      // User clicked "是，去选择" → return to edit
      return false;
    } catch (action) {
      if (action === 'cancel') {
        // User clicked "否，提交" → proceed
        return true;
      }
      // User clicked close → cancel submit
      return false;
    }
  }

  // Scenario 3: Has accepted → proceed
  return true;
},
```

## 6. 数据流

```
AiSuggestionPanel (checkbox _accepted)
  │
  │  @acceptance-change
  ▼
TemplateContent (通过 ref 暴露 hasGeneratedSuggestions / hasAnyAccepted)
  │
  │  ref.hasGeneratedSuggestions() / ref.hasAnyAccepted()
  ▼
TemplateAction.validateAiSuggestion()
  │
  ├─ VUE_APP_CHANNEL !== 'INA' → 跳过校验，直接返回 true
  ├─ 未生成 → $alert 阻止提交
  ├─ 已生成+无勾选 → $confirm 二次确认
  └─ 已生成+有勾选 → 正常提交
```
