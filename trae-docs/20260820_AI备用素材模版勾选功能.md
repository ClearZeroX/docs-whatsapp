# AI 备用素材模版勾选功能

## 1. 功能概述

在素材模板编辑页面的 AI 内容建议区域，新增运营勾选功能，用于控制是否将 AI 生成的内容作为 AI 备用素材模版。

### 1.1 核心流程

1. 运营在 AI 内容建议区域勾选"接受该素材模版下所有AI生成body生成AI备用素材模版"或"接受该body生成AI备用素材模版"
2. 点击"更多"展开 AI 备用素材建议区域，调用 `generate` 接口（不传泳道）生成建议，仅生成一次
3. 更多展开后可勾选"拒绝该body生成AI备用素材模版"
4. 提交时校验至少勾选了一个选项，否则阻止提交
5. 编辑/查看回显时根据 status 接口自动勾选

### 1.2 交互逻辑表

| 操作 | 结果 |
|------|------|
| 勾选"接受所有body" | 禁用单body勾选，默认选中现有body调用 `batchGenerate`，**不禁用+添加** |
| 新增body后（"接受所有"已勾选） | 提示"检测到新增body"，点击重新生成，过滤已生成过的 |
| 勾选"接受该body" | 仅标记当前body |
| 点击"更多"展开 | 调用 `generate`（不传泳道），仅生成一次，展示建议 + 评分 + `☐ 拒绝` |
| 点击"成本优先AI建议" | 展开实时AI建议区域（按泳道、多轮）—— 与"更多"展开互不影响 |
| 编辑/查看回显 | 调 status 接口（按 materialId），已生成过 → 自动勾选 |
| 提交时三选一未勾选 | 弹窗提示 |
| 提交时 — 有勾选body | 调 status 校验，处理中 → 弹窗等待；完成 → 提交 |

#### 3.2.5 勾选交互逻辑

```javascript
// 勾选"接受所有body"
handleAcceptAllChange(val) {
  if (val) {
    this.acceptThis = false;  // 禁用单body勾选
    this.batchGenerateAll();  // 调用 batchGenerate，传入所有现有body的clientMaterialKey
    this.$emit('accept-all-change', true);
  }
}

// 勾选"接受该body"
handleAcceptThisChange(val) {
  if (val) {
    this.$emit('accept-this-change', this.activeClientKey, val);
  }
}

// 勾选"拒绝该body"
handleRefuseThisChange(val) {
  this.$emit('refuse-this-change', this.activeClientKey, val);
}

// 点击"更多"
handleMoreExpand() {
  this.moreExpanded = true;
  this.callGenerateForBackup();  // 调用 generate 接口，不传泳道
}
```

#### 3.3.4 新增 body 时的处理

当"接受所有"已勾选，新增 body 时：
- 新 body 默认为待确认状态

- 点击"为新增body重新生成"后调用 `batchGenerate`，过滤已生成过的 body

### 3.4 TemplateAction.vue 改动

#### 3.4.1 提交前校验

```javascript
async validateBackupMaterial() {
  // 获取所有body的勾选状态
  const acceptanceStatus = this.$refs.templateContent?.getBackupMaterialStatus();
  if (!acceptanceStatus) return true; // 无勾选状态，允许提交

  // 检查是否至少有一个body勾选了
  const hasAnyAccepted = Object.values(acceptanceStatus).some(s => s !== null);
  if (!hasAnyAccepted) {
    await this.$alert(
      this.$t('aiSuggestion.backupMaterialRequired'),
      this.$t('common.tip'),
      { confirmButtonText: this.$t('common.confirm') }
    );
    return false;
  }

  // 检查勾选body的生成状态
  const acceptedKeys = Object.entries(acceptanceStatus)
    .filter(([_, s]) => s !== null)
    .map(([key]) => key);

  const statusRes = await backupMaterialStatus({ clientMaterialKeys: acceptedKeys });
  if (statusRes.data?.processingCount > 0) {
    await this.$alert(
      this.$t('aiSuggestion.backupMaterialProcessing', { 
        done: statusRes.data.successCount, 
        total: acceptedKeys.length 
      }),
      this.$t('common.tip'),
      { confirmButtonText: this.$t('common.confirm') }
    );
    return false;
  }

  return true;
}
```

### 3.5 API 新增

```javascript
// src/api/aiSuggestion.js

// Batch generate AI backup material suggestions (async)
export function batchGenerate(data) {
  return request({
    url: `${BASE}/batchGenerate`,
    method: "post",
    data,
  });
}

// Query backup material generation status
export function backupMaterialStatus(data) {
  return request({
    url: `${BASE}/backup-material/status`,
    method: "post",
    data,
  });
}
```

### 3.6 编辑/查看回显

```javascript
// AiSuggestionPanel.vue mounted/watch
async loadBackupMaterialStatus() {
  if (!this.materialId) return;
  const res = await backupMaterialStatus({
    materialId: this.materialId,
    clientMaterialKeys: [this.activeClientKey],
  });
  if (res.code === 200 && res.data) {
    const item = res.data.items?.find(i => i.clientMaterialKey === this.activeClientKey);
    if (item?.status === 'SUCCESS') {
      // 已生成过，判断是否所有body都生成过
      if (res.data.successCount === res.data.totalCount) {
        this.acceptAll = true;
      } else {
        this.acceptThis = true;
      }
    }
  }
}
```

## 6. 与现有功能的关系

| 现有功能 | 影响 |
|---------|------|
| 实时 AI 建议（成本优先/通用） | 不受影响，独立展开收起 |
| 泳道选择 | 实时AI建议仍按泳道生成；更多展开不区分泳道 |
| 反馈重新生成 | 仅实时AI建议可用；更多展开区域不支持 |
| 评分 | 两者都支持 |
| 添加 body | "接受所有"勾选后不禁用，但新增body需重新确认 |
| 编辑/查看回显 | 新增 status 接口回显逻辑 |
