# 20261112_尼日钱包素材品类与标签方案_线上全量复查版

# 1. 结论 / Findings

建议8个品类、16个不同标签，每品类配置2个候选标签、共8条可选规则。包含7个可识别业务品类和1个占位待复核品类；未复用印尼分类。话费、流量和返现同时出现的正文归组合礼包，不能按关键词优先级吞入单项话费。

Recommend 8 categories and 16 distinct tags (two candidates per category), with 8 optional rules. Seven business categories plus one placeholder-review category; derived from Nigerian wallet evidence, not Indonesian taxonomy.

All figures count available stored records, not campaign performance. Material-group counts are not combination counts. Historical and inactive versions are retained and separately disclosed.

# 5. 组合关联、反例与执行边界 / Joins and Limitations

组合BODY/轮播BODY关联缺失id：[]。按精确material_id关联，不将同组所有BODY拼接成虚构模板。HEADER/按钮只作语境，不可替代正文证据。4条CAROUSEL为cardIds配置，不作为可读业务正文；轮播BODY字段关联的真实BODY仍纳入。

异常例：group44同组两条BODY分别含₦100/₦99与₦1001/₦999，不据此创建新金额品类；group41同时声称权益到账和No action is required，标签可共存但不能据此证明已实际入账。仅文本声明，不验证金融事实。

BODY占位共3条，保留待复核。未读tag_relation，排名是确定性文本规则召回而非现有绑定量；不是LLM正式打标结果，更不是转化效果。Two candidates per category does not mean both tags must be emitted. All rules remain optional (isRequired=0).

JSON结构对照当前MaterialTagConfigJobCommand：action/target/items.categories|tags|rules；TAG不含materialCategoryCode；RULE scope GLOBAL、isRequired0；本次仅生成文档，不执行导入、不写DB。sourceType0表示人工方案配置，status1为导入建议状态。
