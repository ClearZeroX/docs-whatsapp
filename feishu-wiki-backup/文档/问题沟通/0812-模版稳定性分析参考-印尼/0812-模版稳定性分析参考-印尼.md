## 五、可配置的伪装规则建议

1. BODY 伪装规则：
   - 所有营销优惠必须前置声明为「系统自动分配/日志记录」
   - 禁止使用 segera、jangan lewatkan、dapatkan sekarang 等祈使动词
   - 必须至少出现 1 次安全词：log harian / sistem otomatis / tidak ada tindakan
2. HEADER 伪装规则：
   - 高风险素材优先将 IMAGE 改为 TEXT 类型，并插入至少 1 个事务变量
   - 保留 IMAGE 时禁止使用带促销文字的宣传图
3. BUTTONS 伪装规则：
   - 禁止使用行动号召文案，统一替换为：Periksa Status / Lihat Detail / Cek Log
   - 避免使用感叹号、表情符号在按钮文案中
4. Emoji 伪装规则：
   - 仅允许使用 📢 ✅ ⏱ 📊 中性系统类表情，禁止使用 🎁 🎉 🤑 营销类表情
