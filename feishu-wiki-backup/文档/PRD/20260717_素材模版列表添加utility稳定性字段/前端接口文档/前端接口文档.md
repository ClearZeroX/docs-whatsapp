# 前端接口文档

本文档仅说明 **pageInfo** 接口返回中新增的 **templateStats** 字段，供前端开发对接使用。

## 接口概述

**地址**：POST /admin-api/material/page

**说明**：分页查询素材组列表，每条记录新增 **templateStats** 字段，封装模版统计信息与稳定性评级。

## templateStats 字段结构

| 字段 | 类型 | 说明 |
|---|---|---|
| utilityCount | Long | 当前可用中通知类（UTILITY）模版数量 |
| totalTemplateCount | Long | 当前可用模版总数量 |
| utilityPercent | Double | 当前可用中通知类占比，范围 0~1 |
| historyUtilityCount | Long | 历史所有（含已下架/暂停）通知类模版数量 |
| historyTotalTemplateCount | Long | 历史所有模版总数量 |
| historyUtilityPercent | Double | 历史所有通知类占比，范围 0~1 |
| stabilityLevel | String | 稳定性等级：S / A / B / C / D，从高到低 |
| stabilityReason | String | 稳定性等级说明，如"当前可用占比50.0%，等级B" |

## JSON 示例

```json
"templateStats": {
  "utilityCount": 10,
  "totalTemplateCount": 20,
  "utilityPercent": 0.5,
  "historyUtilityCount": 30,
  "historyTotalTemplateCount": 50,
  "historyUtilityPercent": 0.6,
  "stabilityLevel": "B",
  "stabilityReason": "当前可用占比50.0%，等级B"
}
```

## 稳定性等级说明

| 等级 | 含义 | 典型条件 |
|---|---|---|
| S | 极稳定 | 当前可用占比 ≥ 80% 且总数 ≥ 50 且历史占比 ≥ 70% |
| A | 稳定 | 当前可用占比 ≥ 60% 且总数 ≥ 20 且历史占比 ≥ 50% |
| B | 较稳定 | 当前可用占比 ≥ 40% 且总数 ≥ 10 |
| C | 一般 | 当前可用占比 ≥ 20% |
| D | 待提升 | 以上均不满足（兜底等级） |

等级判定规则可通过 Apollo 配置中心热更新，无需发版。

## 前端使用注意事项

1. templateStats 可能为 null：当统计数据尚未计算或缓存过期时，该字段为 null，前端需做好判空处理，建议展示 "-" 或空状态。
2. percent 字段为 0~1 小数：utilityPercent 和 historyUtilityPercent 均为 0~1 的 Double 值，前端展示百分比时需自行乘以 100 并格式化，如 0.5 → "50%"。
3. stabilityLevel 可能为空字符串：当统计数据存在但稳定性评级尚未计算时，该字段可能为空，建议前端兜底显示 "-"。
