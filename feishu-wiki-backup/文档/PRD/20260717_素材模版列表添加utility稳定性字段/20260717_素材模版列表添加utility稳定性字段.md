# 素材组模版统计优化设计

## 背景

## 核心思路

所有统计都基于 `message_template_waba` 中满足条件的数据进行计算，按不同过滤维度切分出"当前可用"和"历史所有"两套统计值。

```
message_material_template (非 DELETED) → 查出 group→templateId 映射
    ↓
message_template_waba (IN allTemplateIds) → rawWabaList
    ├── filter by materialHistoryStatusList → historyWabaList (历史所有)
    └── filterMessageTemplateWaba(list, true) → usableWabaList (当前可用)
    ↓
逐 group 计算：在 usableWabaList / historyWabaList 中按 templateId 匹配统计
    ↓
稳定性评级 → 写 response + 写 cache
```

## 方法设计

### 入口：batchFillMaterialTemplateStabilityStat

```java
private void batchFillMaterialTemplateStabilityStat(
    List<MessageMaterialGroupRespDTO> respList,
    List<MessageMaterialGroup> records)
```

由 `getMaterialGroupRespDTOList` 调用。

### 步骤

#### 1. 前置检查

- businessConfig.getMaterialGroupStabilitySwitch() 关闭 → 直接返回
- respList 或 records 空 → 直接返回

#### 2. 缓存命中检查

- 构建 Map<Long, MessageMaterialGroupRespDTO> idToResp
- 遍历 records，对每个 groupId：
   - 缓存命中 → stats 写入 DTO，continue
   - 缓存未命中 → 加入 uncachedGroupIds
- 如果 uncachedGroupIds 为空 → 全部命中，直接返回

#### 3. 批量加载所有模板 ID

```java
// 查询 message_material_template (非 DELETED) 获取所有 templateId 按 group 分组
Map<Long, Set<String>> groupAllTemplateIds = batchLoadAllTemplateIds(uncachedGroupIds);
// 合并所有 templateId
Set<String> allTemplateIds = groupAllTemplateIds.values().stream()
    .flatMap(Set::stream).collect(Collectors.toSet());
```

如果 `allTemplateIds` 为空 → 所有未缓存 group 都无模板，写空 stats + 缓存后返回。

#### 4. 批量查询 message_template_waba

```java
List<MessageTemplateWaba> rawWabaList = messageTemplateWabaService.list(
    Wrappers.lambdaQuery(MessageTemplateWaba.class)
        .in(MessageTemplateWaba::getMessageTemplateId, allTemplateIds));
```

如果 `rawWabaList` 为空 → 所有未缓存 group 都无 waba 数据，写空 stats + 缓存后返回。

#### 5. 过滤出两套数据

```java
// 历史所有：按状态过滤
List<String> historyStatusList = businessConfig.getMaterialHistoryStatusList();
Map<String, List<MessageTemplateWaba>> historyWabaByTemplateId = rawWabaList.stream()
    .filter(w -> historyStatusList.contains(w.getStatus()))
    .collect(Collectors.groupingBy(MessageTemplateWaba::getMessageTemplateId));

// 当前可用：filterMessageTemplateWaba 过滤
List<MessageTemplateWaba> usableWabaList = sourcePoolService.filterMessageTemplateWaba(rawWabaList, true);
Map<String, List<MessageTemplateWaba>> usableWabaByTemplateId = usableWabaList.stream()
    .collect(Collectors.groupingBy(MessageTemplateWaba::getMessageTemplateId));
```

#### 6. 单遍统计计算

对每个 `uncachedGroupId`：

- 获取该 group 的 Set<String> templateIds（来自 groupAllTemplateIds）
- 当前可用：在 usableWabaByTemplateId 中，只统计这些 templateId 匹配到的 waba
   - utilityCount：category=UTILITY 的数量
   - totalTemplateCount：匹配到的总 waba 数
   - utilityPercent = utilityCount / totalTemplateCount
- 历史所有：在 historyWabaByTemplateId 中，只统计这些 templateId 匹配到的 waba
   - historyUtilityCount、historyTotalTemplateCount、historyUtilityPercent
- 稳定性评级：调用 materialGroupStabilityService.evaluate(...)

#### 7. 写缓存和 response

```java
MaterialGroupTemplateStatsVO stats = 计算出的 stats 对象;
idToResp.get(groupId).setTemplateStats(stats);
templateTypeStatsCache.put(groupId, stats);
```

## 缓存策略

- 键：groupId (Long)
- 值：MaterialGroupTemplateStatsVO
- TTL：10 分钟（沿用现有 templateTypeStatsCache 配置）
- 淘汰：最大 2000 条（超出按 LRU 淘汰）

## 评级规则

三重门槛：既要当下表现好（数量足 + 占比高），又要历史稳定（历史占比也高），代表"长期高质量、当前规模充足"的素材组。
