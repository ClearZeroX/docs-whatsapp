# 报告示例-持续优化

## 示例一

````Markdown
一、概览与核心结论

- 模板总数：389
- 稳定组占比：51.4%（200个）
- 不稳定组占比：48.6%（189个）
- 核心结论：本次分析发现，导致降级的最致命因素是 BODY 含直接营销号召话术、按钮使用强转化文案、未添加事务性免责声明。仅靠 IMAGE Header 本身不是降级原因，真正触发 MARKETING 判定的是文案中暴露的促销意图。

二、BODY 文本"雷区"与"安全区"

风险关键词 Top 5（出现在不稳定组且易触发营销判定）
- `Dapatkan Sekarang`（立即获取）: 72 次
- `promo`（促销）: 127 次
- `jangan lewatkan`（不要错过）: 81 次
- `Ambil Penawaran`（领取优惠）: 31 次
- `kesempatan`（机会）: 94 次

安全关键词 Top 5（出现在稳定组且增加事务性感知）
- `log harian`（系统日志）: 112 次
- `tidak ada tindakan yang diperlukan`（无需操作）: 97 次
- `sistem otomatis`（系统自动）: 89 次
- `status akun`（账户状态）: 76 次
- `laporan berkala`（定期报告）: 63 次

三、反例深挖与伪装改写演示（核心章节）

反例模板详情（数据来源于不稳定组）
- 模板名称/ID：`sucai_free30d_01_uf_am260722_8hfwv` / 1051122
- 原始 BODY：
```
PROMO 30 HARI BEBAS BUNGA PINJAMAN UNTUKMU ✅😊🆓
Ingin pinjam uang tanpa bayar bunga sama sekali? Dapatkan limit hingga Rp200 Juta dengan proses 3 langkah mudah! Dana masuk rekening  mulai dari 15 detik 🏆
Tidak perlu banyak dokumen, dana siap pakai buat semua keperluan sehari-hari 🍔🛵🏬.
```
- HEADER 类型：IMAGE
- BUTTONS：URL + "Dapatkan Sekarang"
- 降级原因分析：
  1. 雷区词：开头直接标注 `PROMO`，出现 `Dapatkan` 强营销动词。
  2. 意图暴露：直接询问用户借款意愿，无任何事务性包装。
  3. 按钮风险：按钮文案为典型营销转化号召。

伪装后修改建议（Keep MARKETING Purpose, Wear UTILITY Skin）
- 修改后 BODY：
```
📢 Pembaruan Sistem: Akun Anda telah terdaftar untuk skema bebas bunga 30 hari ✅
Berdasarkan pengecekan otomatis, nomor Anda memenuhi syarat akses limit hingga Rp 200.000.000 dengan jalur pencairan 15 detik.
Informasi ini tercatat sebagai log harian sistem. Tidak ada tindakan yang diperlukan saat ini.
```
- 修改后 HEADER：保留 IMAGE，建议在图片角落添加小字 `Status Akun Otomatis`
- 修改后 BUTTONS：URL + "Periksa Status Akun"
- 修改逻辑说明：
  1. 词汇替换：删除 `PROMO` 关键词，将"获取限额"改为"系统已注册资格"，保留全部优惠信息但包装为系统自动通知。
  2. 结构伪装：追加 `log harian sistem`、`tidak ada tindakan yang diperlukan` 安全声明，营造非营销错觉。
  3. 按钮转向：将"立即获取"改为"查看账户状态"，在不改变跳转目标的前提下，伪装为事务性操作入口。

四、正例参考（稳定组标杆模板）

正例 1：`sucai_u_17_df_am260723_war80` / 1051808
- BODY：
```
📢 Pembaruan server: Sistem telah memastikan alokasi limit awal hingga Rp 200.000.000 untuk nomor Anda, lengkap dengan opsi bebas bunga selama 30 hari 💪.
Informasi ini otomatis diterbitkan sebagai log harian. Anda tidak perlu melakukan tindakan apa pun saat ini💰.
```
- HEADER 类型：IMAGE
- BUTTONS：URL + "Periksa Status Saldo"
- 安全特征拆解：
  1. 句式特征：全程使用陈述句，描述系统操作结果，不向用户发起请求。
  2. 关键词：强制追加 `log harian`、`tidak perlu melakukan tindakan` 安全锚点。
  3. 变量运用：虽未使用变量，但通过"系统自动发布"营造事务感。
  4. 可模仿点：所有优惠信息全部包装为"系统已经完成的操作"，而非"向用户推销的产品"。

五、可配置的伪装规则建议

1. BODY 伪装规则：
   - 禁止开头直接出现 `PROMO / Diskon / Penawaran` 等词，所有优惠必须包装为「系统自动分配的账户权益」
   - 任何营销文案末尾必须追加至少一句安全声明：`Informasi ini adalah log sistem otomatis, tidak ada tindakan yang diperlukan`
2. HEADER 伪装规则：
   - 可保留 IMAGE，但禁止使用纯广告海报，建议图片添加系统状态栏、账户通知类视觉元素
3. BUTTONS 伪装规则：
   - URL 按钮文案禁用 `Dapatkan / Beli / Ambil / Shop`，统一改用 `Periksa Status / Lihat Detail / Cek Akun`
4. Emoji 伪装规则：
   - 稳定组仅使用 `📢 ✅ ⚡ 📊` 系统类表情，禁止使用 `🔥 🎉 🎁 🤑` 促销类表情，单条模板 emoji 不超过 3 个。
````
